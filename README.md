🌱 AgroKit Ecológico
📌 Descripción del proyecto

AgroKit es una plataforma digital orientada a facilitar la comercialización directa de productos agroecológicos entre campesinos productores y consumidores urbanos. El sistema busca reducir la intermediación, promover el consumo responsable y mejorar el acceso a alimentos frescos y sostenibles.

Este proyecto se desarrolla en el marco académico de ingeniería de software, siguiendo un enfoque iterativo basado en la metodología Scrum. La presente versión corresponde a un prototipo funcional inicial (MVP), enfocado en validar la interacción del usuario y los flujos principales del sistema.

🎯 Objetivo

Desarrollar un prototipo funcional que permita validar la viabilidad de una plataforma que conecte productores rurales con consumidores urbanos mediante la venta de kits agroecológicos.

🚀 Estado del proyecto

🔹 Prototipo funcional inicial (MVP)
🔹 Interfaces principales implementadas
🔹 Navegación y flujos básicos operativos
🔹 Backend y base de datos aún en fase de definición

🧩 Funcionalidades actuales
Registro de usuarios
Inicio de sesión
Visualización de productos
Simulación de compra

Estas funcionalidades permiten validar el comportamiento general del sistema sin implementar aún la lógica completa de negocio.

📂 Estructura del proyecto

El proyecto se organiza en componentes y páginas, siguiendo buenas prácticas de desarrollo frontend. Esta estructura permite una separación clara de responsabilidades y facilita la escalabilidad del sistema en futuras fases.

🧠 Arquitectura (visión general)

El sistema sigue una arquitectura cliente-servidor, donde:

El frontend gestiona la interacción con el usuario
El backend (propuesto) manejará la lógica del sistema
La base de datos (propuesta) almacenará la información
🔄 Metodología de trabajo

El desarrollo del proyecto se realiza bajo la metodología ágil Scrum, organizando el trabajo en Sprints y priorizando funcionalidades a partir de historias de usuario.

📈 Evolución del proyecto

El repositorio fue creado en una fase inicial del proyecto, correspondiente al desarrollo del prototipo de diseño. Para la presente fase, se han incorporado avances hacia un prototipo funcional, incluyendo la implementación de interfaces y validación de flujos principales.
