# 🌱 AgroKit Ecológico

## 📌 Descripción del proyecto

AgroKit es una plataforma digital orientada a facilitar la comercialización directa de productos agroecológicos entre campesinos productores y consumidores urbanos. El sistema busca reducir la intermediación, promover el consumo responsable y mejorar el acceso a alimentos frescos y sostenibles.

Este proyecto se desarrolla en el marco académico de Ingeniería de Software, siguiendo un enfoque iterativo basado en la metodología Scrum. La presente versión corresponde a la tercera fase de desarrollo, en la cual se consolidó el prototipo funcional, se definió la arquitectura técnica del sistema y se incorporaron prácticas de integración continua y despliegue automatizado.

---

## 🎯 Objetivo

Desarrollar una plataforma digital que permita validar la viabilidad de conectar productores rurales con consumidores urbanos mediante la comercialización de kits agroecológicos, promoviendo una relación directa entre oferta y demanda.

## 📂 Estructura del proyecto

El proyecto se organiza mediante una estructura modular basada en componentes y páginas, permitiendo una adecuada separación de responsabilidades y facilitando la escalabilidad del sistema.

La organización del código favorece el mantenimiento, la reutilización de componentes y la incorporación de nuevas funcionalidades en futuras iteraciones.

---

## 🧠 Arquitectura del sistema

El sistema adopta una arquitectura cliente-servidor.

* El frontend gestiona la interacción con el usuario.
* El backend (propuesto) administrará la lógica de negocio.
* La base de datos (propuesta) almacenará la información del sistema.

La arquitectura fue documentada mediante diagramas C4 Nivel 1 (Contexto) y Nivel 2 (Contenedores).

---

## 🔄 Metodología de trabajo

El proyecto se desarrolló utilizando la metodología ágil Scrum, organizando el trabajo mediante Sprints y priorizando las funcionalidades a partir de historias de usuario.

Se utilizó Trello como herramienta de gestión para el seguimiento de tareas, control del backlog y planificación de actividades.

---

## ⚙️ Integración continua y despliegue

El repositorio incorpora un flujo básico de integración continua mediante GitHub Actions, permitiendo validar automáticamente la construcción del proyecto ante nuevos cambios.

El despliegue se realiza utilizando Vercel, plataforma conectada directamente al repositorio de GitHub para automatizar la publicación de nuevas versiones.

---

## 🐳 Contenerización

Como parte de la fase final del proyecto, se incorporó una configuración inicial mediante Docker y Docker Compose, permitiendo preparar el sistema para futuras implementaciones en entornos contenerizados.

---

## 📈 Evolución del proyecto

El repositorio fue creado durante las primeras fases del proyecto académico para alojar los prototipos iniciales. Posteriormente se incorporaron mejoras funcionales, ajustes derivados de pruebas de usabilidad, definición arquitectónica y despliegue en línea, permitiendo evolucionar progresivamente desde un prototipo de diseño hacia un prototipo funcional.
